# Getting Started

**Fenominal** is a high-performance HPO-based text mining engine written in Rust, with Python bindings for integration into data science workflows.

It implements the algorithm described in:

> Groza T, et al. (2023)  
> *Term-BLAST-like alignment tool for concept recognition in noisy clinical texts*  
> Bioinformatics 39(12): btad716  
> https://pubmed.ncbi.nlm.nih.gov/38001031/
